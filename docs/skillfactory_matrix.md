# Соответствие шкале Skillfactory

Сверка по сохранённым материалам курса «Этапы выполнения проекта», приложениям А–Д и странице «Подготовка материалов и оценивание». Разделы требуют 8–12 требований, 4–7 шагов с контрактами, аудит в новом чате, хотя бы один пакет передачи, минимум 8 различных финальных сценариев и 3 граничных, разбор сбоя и акт. Подготовка к отправке требует один отчёт в DOCX, PDF или Google Docs и один ZIP. Максимум проекта 50 баллов, итоговые тесты платформы дают ещё до 50 баллов. Каждый подпункт оценивается целиком. Полное отсутствие записей о реальных запросах обнуляет проект. Баллы в этом документе не начисляются.
