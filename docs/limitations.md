# Ограничения и статус сдачи

- Авторизованная форма итогового проекта недоступна. Страница курса открыла вход в Skillfactory. Комплект подготовлен по сохранённым выдержкам официального задания: этапам, приложениям, подготовке материалов и подробной шкале. Состояние живой формы и отдельное вводное описание не подтверждены.
- В журнале видны исходный Q01 и результаты прежней работы. Полный ответ Q01 и отдельная предшествующая служебная отметка с независимым временем не восстановлены. Критерии R1 сохранены в Git и использовались при дополнительной работе этой сессии.
- По Q02 есть полный ответ реального отдельного чата. Сообщения A–F, которые подготовлены как контракты, имеют метку NOT_SENT. Сам факт наличия шаблона не подтверждает отправку.
- Техническая приёмка в комплекте выполнена Codex. Утверждение человеком и оценка преподавателя отсутствуют.
- Windows-проверка исполнена на OpenJDK 21 с `--release 17`. Прогоны непосредственно на Java 17 выполнены GitHub Actions.
- Для GitHub Actions сохранён настоящий снимок успешной исходной сборки. Остальные изображения — подписанные иллюстрации по логам фактических запусков. Операции в Windows-браузере завершились, когда не удалось подтвердить адрес открытой вкладки.
- Открытых дефектов для R01–R10 по результатам набора нет. Проверена учебная CLI по указанным случаям. Реальные пароли для демонстрации не используются.
