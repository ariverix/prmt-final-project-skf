# Постановка задачи — версия R1

Дата: 21.11.2026. Требования и критерии завершения зафиксированы до формирования исходника.

## Назначение и границы

Консольная программа проверяет одну вымышленную строку за запуск и выводит `OK` либо перечень кодов нарушений. Пароли не сохраняются и не отправляются в сеть. Нет GUI, базы данных, регистрации и оценки криптостойкости.

## Требования

| ID | Проверяемое правило |
| --- | --- |
| R01 | Файл `src/PasswordValidator.java` без `package`, Java 17, только стандартная библиотека, консольный запуск. |
| R02 | Читать первую строку стандартного ввода целиком, включая пробелы. Символ перевода строки не включать. |
| R03 | Длина 8–16 включительно по `String.length()`; иначе `LEN`. |
| R04 | Есть хотя бы одна заглавная латинская буква A–Z; иначе `UPPER`. |
| R05 | Есть хотя бы одна цифра 0–9; иначе `DIGIT`. |
| R06 | Разрешены A–Z, a–z, 0–9. Иначе `CHAR`; у пустого ввода CHAR не выводится. |
| R07 | Все четыре правила выполнены → ровно одна строка `OK`. |
| R08 | Все нарушения выводить без повторов по одному в строке: LEN, UPPER, DIGIT, CHAR. |
| R09 | Пустая строка или EOF перед первой строкой → LEN, UPPER, DIGIT, без аварийного завершения. |
| R10 | Последующие строки игнорировать. Не выводить приглашений, пояснений и проверяемого значения. |

## Критерии завершения (до реализации)

1. Финальная версия компилируется с `javac --release 17` и запускается по инструкции.
2. Выполнены 13 разных сценариев, включая минимум три граничных.
3. R01–R10 связаны с проверками, ожидаемыми и фактическими выводами.
4. Исходный код программы — 50–150 непустых строк без комментариев; тестовый код отдельно.
5. Сохранены фактический запрос, журнал, условные промпты, разбор хотя бы одного реального или явно учебного дефекта.
6. Акт приёмки содержит решение, свидетельства и оставшиеся ограничения.

После начала работы требования не меняют под фактический вывод программы. Изменение оформляется новой версией.
