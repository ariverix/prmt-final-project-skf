# D01 — намеренно созданный учебный сбой

Тип: учебная ошибка, внесённая вручную в отдельную копию, а не ошибка модели.

- R03, T01: строка `Abcdefg1` длиной 8 символов.
- Ожидание: `OK`. Факт на учебной дефектной версии: `LEN`.
- Причина: условие `password.length() > MIN_LENGTH` исключало нижнюю границу.
- Затронуты правило R03 и проверки T01–T04. Остальные условия не изменялись.
- Точка возврата: проверка длины в C, затем D.
- Исправление: восстановлено `>= MIN_LENGTH`. Внесено вручную (H02), 0 запросов модели на исправление.
- Проверены T01, T02, затем весь итоговый набор T01–T13 (13/13).
- Свидетельства: `before.txt`, `after.txt`, две версии исходника, файлы `evidence/final/`.
- Решение: учебный дефект исправлен и закрыт.
