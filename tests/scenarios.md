# Сценарии запуска T01–T14

Из корня проекта скомпилировать исходник и раннер по README. Для каждого сценария раннер запускает отдельный процесс `java -cp build PasswordValidator`, записывает в stdin указанные байты UTF-8 и закрывает поток. Пользовательские строки синтетические. Обозначение LF означает байт перевода строки, EOF — закрытие stdin без байтов. В таблице символ `/` разделяет строки ответа. Каждый вывод заканчивается одним переводом строки, stderr пуст, код выхода 0. Допуск LF/CRLF относится к сравнению системных окончаний вывода.

| ID | Точный stdin | Ожидаемый и фактический вывод | Проверка |
| --- | --- | --- | --- |
| T01 | `Abcdefg1` + LF | OK | R03/R07, ровно 8 |
| T02 | `Abcdefghijklmno1` + LF | OK | R03/R07, ровно 16 |
| T03 | `Abcdef1` + LF | LEN | R03, 7 |
| T04 | `Abcdefghijklmnop1` + LF | LEN | R03, 17 |
| T05 | `abcdefg1` + LF | UPPER | R04, строчные буквы |
| T06 | `Abcdefgh` + LF | DIGIT | R05, без цифры |
| T07 | `Abcdef 1` + LF | CHAR | R02/R06, внутренний пробел |
| T08 | LF | LEN / UPPER / DIGIT | R06/R08/R09, пустая строка |
| T09 | `abc` + LF | LEN / UPPER / DIGIT | R03–R05/R08, три ошибки |
| T10 | `Abcdef#1` + LF | CHAR | R06, запрещённый символ |
| T11 | `Abcdefg1` + LF + `abc` + LF | OK | R02/R07/R10, вторая строка игнорируется |
| T12 | один пробел + `Abcdefg1` + один пробел + LF | CHAR | R02/R06, пробелы по краям |
| T13 | EOF | LEN / UPPER / DIGIT | R06/R08/R09, нет первой строки |
| T14 | `#` + LF | LEN / UPPER / DIGIT / CHAR | R03–R06/R08/R10, все коды в порядке |

T01–T13 сохранены из исходного проекта и основаны на примере в приложениях А–Б. T14 добавлен как отдельная проверка существующего R08. Все 14 прошли. Для каждого ID фактический протокол находится в `evidence/final/<ID>.txt`. Полный порядок и отсутствие лишнего stdout проверяются во всех сценариях.

- V01 — компиляция и запуск с Temurin 17. Подтверждение в `evidence/ci/java17_final_run.txt`.
- V02 — осмотр `src/PasswordValidator.java`: без package, импорт java.io, тесты отдельно. После исключения пустых строк 56, комментариев в файле нет. Подтверждение в `evidence/compile.txt`.
