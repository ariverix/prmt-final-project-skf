# Не отправлено — шаг A

**Цель:** проверить однозначность требований.
**Вход:** полный текст R01–R10 из docs/requirements.md, версия R1.
**Действие:** найти противоречия, неоднозначности и недостающие правила.
**Ограничения:** не добавлять функции, не менять принятые правила.
**Выход:** таблица ID / замечание / вопрос / минимальная правка.
**Критерий:** рассмотрены все десять требований, каждое замечание проверяемо.
**Неопределённость:** при недостатке данных задать вопрос человеку.
