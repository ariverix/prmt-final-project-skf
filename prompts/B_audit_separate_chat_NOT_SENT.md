# Не отправлено — обязательный аудит в отдельном чате

**Цель:** найти недостатки R1 и карты P1.
**Вход:** полный текст docs/requirements.md R1 и docs/process.md P1.
**Действие:** проверь все шесть шагов, совместимость входа/выхода, все КТ1–КТ4, маршруты возврата после ошибки и условия остановки.
**Ограничения:** не придумывай новые функции программы, не меняй принятые требования, код не пиши.
**Выход:** таблица «место / дефект / последствие / минимальное исправление / какие сведения отсутствуют».
**Критерий:** замечания связаны с конкретными полями, требованиями и переходами.
**Неопределённость:** если сведений не хватает, перечисли вопросы для человека.

Для зачёта нужно реально открыть другой чат, отправить материалы и сохранить полный ответ и решение по каждому замечанию. Подготовленный файл НЕ является результатом аудита.
