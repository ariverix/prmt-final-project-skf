# Не отправлено — шаг D

**Цель:** проанализировать результаты проверки.
**Вход:** R1, сценарии, исходник и фактические evidence/final/results.tsv.
**Действие:** сопоставить ожидание и фактический вывод для каждого сценария.
**Ограничения:** не утверждать, что модель сама проверила работу программы; не менять критерии задним числом.
**Выход:** таблица ID / требование / ожидание / факт / статус / подтверждение.
**Критерий:** покрыты все предоставленные результаты и оставшиеся неизвестные.
**Неопределённость:** отсутствующее подтверждение означает «не проверено».
